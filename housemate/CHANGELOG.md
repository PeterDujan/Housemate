# Changelog

## 1.0.0-beta.3

- Checks on the Overview: a red and green list of what works and what still needs doing (the
  AI sign-in, speech in Home Assistant, Housemate Brain, each speaker's voice assistant and music
  player, each person, house power, errors in the log), each with a button to where it is fixed.
  The Chat tab reads the same list.
- The last setup step shows which speakers still need the assistant, with the names to pick.
- Sign in with your Claude account from the System page: open the link, paste the code back.
- Plainer words across the page, and one Memories to check list instead of two.
- Lists to pick from instead of typed ids: Home Assistant's speech engines, the model, the Fish
  voice, the language and the approval phone.
- One way to save: a Save button shows up under what you change, saves that need a restart say
  so, one restart bar for the page, and a warning before leaving unsaved changes.
- Speaking up is out of the menu until it is available.
- A renamed assistant is renamed in Home Assistant too (with Housemate Brain 0.8.0).

## 1.0.0-beta.2

- The README and the feature list are rewritten in plain English, and the feature list now
  covers everything it does: memory, recall on demand, a character that grows, and how it keeps
  AI use low.

## 1.0.0-beta.1

- First public release.
- The README is a step-by-step install guide; FEATURES.md lists everything it does, with and
  without an AI account.
- No private names left anywhere: the voice hears the assistant's own name and its mishearings
  (from the persona), its Home Assistant states are named after the assistant, and its data
  folders are housemate-voice.
- Clearer wording on the settings page.
- The browser and Windows terminal settings are gone.
